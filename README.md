# MediQueue - Tutor Booking Platform

MediQueue is a modern tutor booking platform where students can browse tutors, view tutor details, and book learning sessions easily. Tutors can create and manage their own tutoring profiles and available slots.

## 🌐 Live Website

🔗 https://mediqueue-client-red.vercel.app/

---

# 🚀 Features

## 🔐 Authentication
- Email & Password Login/Register
- Google Authentication
- JWT Protected Private Routes
- Persistent User Login
- Redirect After Login

## 👨‍🏫 Tutor Features
- Add Tutor Profile
- Update Tutor Information
- Delete Tutor
- Manage Available Slots
- Subject Based Tutor Listing

## 📚 Student Features
- Browse Available Tutors
- Search & Filter Tutors
- View Tutor Details
- Book Tutor Session
- Prevent Duplicate Booking
- Cancel Booked Session

## 🎨 UI Features
- Fully Responsive Design
- Dark / Light Theme
- Dynamic Page Titles
- Beautiful Hero Banner
- Custom 404 Page
- Modern Card Layout
- Pagination
- Toast Notifications

## 📄 Static Pages
- About Page
- Contact Page
- FAQ Page
- Become a Tutor
- Privacy Policy
- Terms & Conditions
